# Alana Nails — protótipo v0.2

Site demonstrativo para nail designer, desenvolvido com Next.js 16, TypeScript, React e Tailwind CSS 4.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Status

Este repositório contém um protótipo de apresentação. Agendamentos e configurações usam `localStorage`, sem compartilhamento entre dispositivos. O painel `/admin` ainda não tem autenticação. Não use dados reais de clientes nem aceite reservas reais nesta versão. Banco de dados, login seguro, proteção contra horários duplicados, pagamentos e notificações precisam ser configurados antes do uso em produção.

O site inclui fotos de referência fornecidas para a apresentação da Alana Nails.
